# Abdel Hady Habib Portfolio

Static bilingual portfolio for a Senior Construction Manager (Mechanical/MEP).

## Production files

- `index.html` - English portfolio entry point
- `ar/index.html` - crawlable Arabic portfolio entry point
- `i18n.js` - synchronized English and Arabic interface/content data
- `Abdel-Hady-Habib-CV.pdf` - downloadable CV
- `assets/` - locally hosted Font Awesome assets
- `images/tools/` - internal-tool screenshot placeholders using dummy data
- `facephoto.png` / `facephoto.webp` - profile image assets

## Local preview

Serve the repository with any static HTTP server. No build process is required. Open `/` for English or `/ar/` for Arabic.

## Production assets

- `images/og-cover.png` is the 1200x630 Open Graph and Twitter sharing image.
- Replace the four files in `images/tools/` only when updated screenshots containing dummy data are available.
- Review any future wording changes in the marked `REVIEW ARABIC` section of `i18n.js`.
